# 未完的夏天

校园生活文字游戏原型。Python 3.12+，无第三方依赖。

## 运行

```sh
cd /workspace/word_game
python server.py
```

默认端口 3000，可用 `PORT` 调整。包括自由输入、行动选项、精力/压力/钱包/好感、本地自动存档及最近100次人生手记。目前是单角色、单场景交互原型，时间每4次行动推进一天；不是完整学期模拟。

默认本地规则演示会明确标注，无法理解任意输入。真实 AI 模式使用兼容 OpenAI Chat Completions 的接口：在服务端安全注入 `GAME_AI_KEY`；可选 `GAME_AI_BASE_URL`（默认 https://api.openai.com/v1）、`GAME_AI_MODEL`（默认 gpt-4.1-mini）。然后重启服务。不要把密钥写入前端或提交到 Git。请求包含玩家行动、状态、当前剧情及最近12次历史；更早历史暂无长期记忆摘要。AI 会产生调用费用。

服务端不会记录接口凭据。AI 数值变化受前端限幅；正式版应将权威状态、存档、身份验证、请求限流和内容审核移到服务端。当前无登录，只适合本地开发，不应直接暴露到公网。浏览器存档仅保留当前一档，清理网站数据会丢失。

场景插图为 CSS 绘制。中文字体可从 Google Fonts 加载，网络不可用时自动使用本地字体。
